# Multi-Skill Agent Pipeline

See [Multi-Skill-Agent-Pipeline/README.md](Multi-Skill-Agent-Pipeline/README.md) for the full write-up.

Three chainable Claude Skills (in .claude/skills/): **jd-writer -> interview-kit -> scorecard-builder** turn a role brief into a job description, interview kit, and a fill-in scorecard CSV. Includes two example runs and a Python quality gate that verifies the chain.
